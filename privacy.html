Skew プライバシーポリシー

最終更新日: 2026年11月2日

Skew(https://skewapp.github.io/)は、曲ごとの「流れやすさ」を調整できるシャッフルプレーヤーです。このページでは、Skew が扱う情報について説明します。

1. 取得する情報

  • Google(YouTube)アカウント: ログインした場合に限り、YouTube のチャンネル名、自分で作成したプレイリスト、そのプレイリストに含まれる動画、「高く評価した動画」を読み取ります(読み取り専用の権限 youtube.readonly のみを使用します)。
  • Spotify アカウント: ログインした場合に限り、プロフィール、プレイリスト、ライブラリの曲、再生状態を読み取り、再生の操作を行います。

2. 情報の使い方

取得した情報は、Skew の画面に曲やプレイリストを表示し、再生するためだけに使います。広告、分析、第三者への提供には一切使いません。

3. 保存場所

Skew には独自のサーバーがありません。曲リスト・設定・ログイン情報(アクセストークン)は、利用者のブラウザ内(localStorage)にのみ保存され、Skew の運営者が受け取ることはありません。通信は、利用者のブラウザから Google(YouTube)・Spotify の公式 API へ直接行われます。

4. 削除と連携の解除

  • Skew の設定画面の「ログアウト」で、ブラウザ内のログイン情報を削除できます。
  • ブラウザのサイトデータを削除すると、Skew に保存されたすべての情報が消えます。
  • Google の連携は Google アカウントの「サードパーティ製のアプリとサービス」から、Spotify の連携は Spotify の「アプリの管理」からいつでも解除できます。

5. Google API サービスの利用

Skew による Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。YouTube の利用には YouTube 利用規約および Google プライバシー ポリシーが適用されます。

6. お問い合わせ

このポリシーに関するお問い合わせは、GitHub の Issues からお送りください。
